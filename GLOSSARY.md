# Budi Gunawan Personal Site

The personal branding website of Budi Gunawan, a fullstack engineer focused on frontend. It presents who Budi is, Budi's work history, projects, and writing.

## Language

### Content

**Post**:
A single article in the Blog, written in English.
_Avoid_: Article, blog, entry

**Draft**:
A Post that is not yet published; it never appears on the live site.
_Avoid_: Unpublished post, WIP

**Tag**:
A topic a Post is about. Tags belong to Posts only.
_Avoid_: Category, label

**Project**:
A piece of work Budi built that is shown on the Projects page as a card.
_Avoid_: Portfolio item, work

**Stack**:
The technologies used to build a Project. Distinct from Tags, even when the same word appears in both.
_Avoid_: Tech tags, tools

**Case Study**:
The long-form write-up of a Project (goals, Stack, problems, lessons learned). Only flagship Projects have one; the rest link out to their repository or live site.
_Avoid_: Project detail, project page

**Featured Project**:
A Project highlighted on the Home page. Every Featured Project has a Case Study.
_Avoid_: Highlighted project, pinned project

**Experience**:
One role in Budi's work history (company, title, period, highlights), shown as part of the About page.
_Avoid_: Job, position, resume entry

**CV**:
The downloadable PDF of Budi's work history, maintained separately from the site.
_Avoid_: Resume
