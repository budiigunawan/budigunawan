# 06: Resume and privacy

**What to build:** The Resume served from Budi's own domain as a PDF, linked from the navigation, with no intervening sign-in or third-party viewer. Alongside it, a privacy page that states what the Contact form stores, why, and who can read it, authored as content so it can be edited without a code change.

**Blocked by:** 01: Scaffold, shell and CI

**Status:** ready-for-agent

- [ ] The Resume is served as a PDF from the site's own domain, and opening the navigation link downloads or displays it without a login.
- [ ] The navigation link is the only Resume surface; there is no resume page route.
- [ ] The privacy page states which data a Contact Message contains, why it is stored, and who can read it.
- [ ] Privacy content is authored as a Legal entry, so text changes need no code change.
- [ ] Both the Resume link and the privacy page are reachable from the footer.
- [ ] The privacy page has a single h1 and is readable at 320px.
