# Posts are MDX in the repo, not Sanity

Sanity Studio was the initial idea for authoring Posts. We chose MDX files in Astro content collections instead. The only author is a developer, Posts benefit from embedding interactive React components, content gets versioned and reviewed in git with the code, and the site stays a fully static build with no CMS account, webhook, or API dependency. Revisit if Posts need to be written outside a code editor (e.g. from a phone) or by non-developers.
